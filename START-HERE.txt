SLIDEIQ — FIRST PLAYABLE SOURCE PROJECT

1. Extract this ZIP into a NEW folder to avoid old scenes and build outputs.
2. Add the extracted SlideIQ-main folder in Unity Hub and open it.
3. Select Tools > SlideIQ > Repair Startup and Open Menu, then press Play.
   Play mode now starts at the SlideIQ menu even if an old cloned scene was open.
4. To check game rules: Tools > SlideIQ > Validate Rules.
5. To build: Tools > SlideIQ > Build WebGL and itch ZIP.
   Install WebGL Build Support through Unity Hub if needed.
6. Upload the generated SlideIQWeb.zip as an HTML game on itch.io.

Included: 3x3 / 4x4 / 5x5 boards; deterministic solvable challenges;
move counter and timer; reset; reveal goal; JSON import/export; music toggle;
responsive tile-themed menu; new scenes; SlideIQ browser loading screen.
Reveal ends an attempt without awarding a win. It shows the goal, not a
step-by-step solution. Difficulty labels indicate board size, not optimal
solution length. Export before closing: there is no automatic progress save.

This source package was checked for scene wiring and its shuffle algorithm
was independently checked on 3,006 boards for solvability and inverse solutions.
Unity is not available in the preparation environment: the C# validation command,
visual checks, and WebGL compilation must be run in your Unity Editor.
No compiled WebGL build is included. The menu uses drawn tiles; inherited cover
assets are retained but are not displayed as SlideIQ branding.

Only Assets, Packages, ProjectSettings, source-control configuration and this
readme are packaged. Old compiled games, recordings, caches, promotional exports
and generated IDE files are omitted.
